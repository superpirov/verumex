# Что запросить у SkyCapital для live-интеграции

Когда дадут API — попроси вот это (по опыту их WhiteLabel / API-интеграции):

## 1. База
- [ ] Base URL (prod + sandbox): `https://.../v1`
- [ ] Аутентификация: API-key в header? HMAC-подпись? IP-whitelist?
- [ ] OpenAPI / Postman-коллекция
- [ ] Тестовые ключи + тестовый стенд СБП

## 2. Курсы и лимиты
- [ ] `GET /rates?from=RUB&to=USDT_TRC20` — формат ответа, TTL фиксации курса (обычно 15-30 мин)
- [ ] Комиссии: покупка СБП 2.5%, продажа 2% — подтверждаются? Кто считает маржу партнёра?
- [ ] Мин/макс: покупка до 2000 USDT instant? Вывод от 1000 ₽? Лимит 600k ₽/мес?

## 3. Заявки
- [ ] `POST /orders` — поля: direction, amount, wallet/phone/bank, KYC-token?
  Ожидаем: `orderId, fixedRate, sbpQrUrl / sbpDeepLink, expiresAt, requisites`
- [ ] `GET /orders/:id` — статусы: `pending_payment → paid → executing → done / aml_hold / expired`
- [ ] Вебхуки: куда слать, подпись `X-Signature`, ретраи?

## 4. СБП
- [ ] C2B-эквайринг: QR формируется на стороне SkyCapital? Deep-link на банк?
- [ ] Выплата на СБП: нужен банк + телефон получателя? 2FA на нашей стороне?

## 5. KYC/AML/Compliance
- [ ] Когда триггерится KYC (сумма/риск)? `kycUrl` в ответе или редирект?
- [ ] AML-скрининг кошельков: коды рисков, автоблок?
- [ ] Документы по операциям: `GET /orders/:id/docs` (PDF)? Оферта 259-ФЗ/115-ФЗ для футера.

## 6. WhiteLabel
- [ ] Можно ли использовать свой домен/логотип и проксировать API через свой бэкенд (чтобы не светить ключ)?
- [ ] Техподдержка 24/7 и лимиты $400/мес сопровождения — актуально?

Пока всё это не получено — работает `mock` в `src/lib/api.ts` с реалистичными курсами и задержками.
